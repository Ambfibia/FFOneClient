# Email

Project active NPC letters from task start-mail flags 4/6, sender and message string;
then first eligible Guide and Nano invitations in table order. Invitations use normal
mission availability and disappear for active/completed owners. Task type is not mail
mode. Login mail notices use the same selection. Sender, subject and body resolve
semantic EN/RU keys; the list truncates to 24 UTF-16 units after Localization::Apply,
while detail retains the full translation. An unchanged projection preserves selection/page.
Guide icon=62×62 at (10,13); FROM/SUBJECT shift79.

While closed, observe mission/mentor/Nano/inventory authority. Newly projected
(mode,task) letters trigger existing arrival sound and the two-second minimap alarm;
unchanged lists/removals do not. Reset observed list per PC. Unsupported/absent mentor
suppresses only mentor invitations, never active NPC letters or mailbox access.

Occupied slots and authoritative item identity survive unavailable art. Trade metadata
is independent of optional icon paths; unsafe/missing images must not abort opening or
refreshing mail. Attachment eligibility, ownership and trade restrictions still apply.

`FFONE_PERF_EMAIL=1` plus `FFONE_PERF_OUTPUT` and `--language en|ru` selects the
optional full-client presentation fixture. It may replay offline authority after an
unauthenticated reset; do not mistake its reopen for tested live selection retention.
Test unchanged projection independently in the production owner.

Keep the player tab below the list's top rim. The guide tab sits below the rim
when inactive, then above it when selected or hovered. Both captions stay above
the artwork.
`FFONE_PERF_EMAIL_TABS=1` extends the email full-client fixture with both folders
and hover on each tab, checking computed UI stack order and capturing six frames.

Новый текст: **79 пунктов**, из них **52** имеют актуальный остаток, **27** исключены по записанным исправлениям. Тесты/приёмка runtime в этой актуализации не запускались. «Исключено» включает code-fixed с указанными ограничениями; это не заявление новой живой приёмки.

Частичный объём: T169 — только RPS-представление; T186 — только звук; T188 — цвет разблокированных фоновых выкриков. T189 — только непринятые магазин/количество/транспорт; T192 — почта (инвентарь и журнал уже приняты); T214 — возврат фокуса в непринятых экранах. T215 — предложение курсора в группе геймпада, не отдельный подтверждённый дефект.

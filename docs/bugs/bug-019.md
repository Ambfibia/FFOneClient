Сохраняется отсутствие движения дорожного траффика из прежней очереди. Новое уточнение: девочка Orchid Bay и призрачная уточка Endsville бегут вместо ходьбы, машины кажутся слишком быстрыми. Найти ID, path и серверную скорость, сравнить с клиентским Walk/Run. Гипотеза обо всех NPC с паттернами не доказана.

## Критерий готовности

Указанные NPC используют ходьбу, машины движутся по своим маршрутам с принятой скоростью; повторный streaming не останавливает движение.

Выполнить адресные регрессии и приёмку изменённого поведения в реальном клиенте. Для обмена/удалённого игрока — два клиента и сервер; для hot-plug — физическое устройство. Нулевой набор тестов не считается проверкой. Ограничения записать явно.

# Bug 14 — Полноценное управление геймпадом

**Приоритет:** P2. **Группа:** Настройки и ввод.  
**Статус активной части:** Частично исправлено по коду; открыто до приёмки с физическим геймпадом и проверки остальных UI-действий.  
**Режим задания:** Работать только над оставшейся частью без найденного исправления.

## Исходные жалобы

- [S76](source-list.md#s76) — Имплементировать управление геймпадом

Объём работы ограничен заданием ниже; исправленные части исходной формулировки исключены.

## Что уже установлено

Поиск Gamepad в клиенте обнаруживает UI/строки настроек; capture_option_binding_input сразу выходит для Pad. option_binding_held обрабатывает клавиатуру/мышь, не pad.

## Владельцы и точки входа

- [crates/ffone-client/src/app/hotkeys.rs](../../../../crates/ffone-client/src/app/hotkeys.rs)
- [crates/ffone-client/src/ui/option/interaction_input_settings.rs](../../../../crates/ffone-client/src/ui/option/interaction_input_settings.rs)

Сначала искать конкретные символы внутри этих владельцев; не читать целиком все перечисленные деревья. Применить подходящий контракт из корневого AGENTS.md.

## Задание агенту

Подключить события Bevy gamepad к существующим action mappings: движение, камера, действия, UI, dead zones, подключение/отключение и переназначение. Сохранить единый владелец input gates.

## Критерий готовности

Настройки геймпада соответствуют реальному вводу; стики не дрейфуют; modal UI не пропускает атаку; отключение устройства не оставляет нажатые действия.

## Проверка

Тесты преобразования осей/кнопок и release, затем реальный геймпад; без устройства не объявлять физический ввод проверенным.

Тест с нулём выполненных случаев не считается проверкой. UI, звук и анимации принимать в реальном клиенте. Если запуск недоступен, оставить это явно незавершённой частью, без заявления о полном исправлении.

## Зависимости и границы

Исправленные пункты и их повторная приёмка не входят в текущую очередь. Не возвращать их как предварительные задачи. При обнаружении существующего конкретного исправления снять соответствующую часть с активной очереди.

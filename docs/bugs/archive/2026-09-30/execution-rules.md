# Выполнение активных Bug N

Родительский AGENTS.md остаётся обязательным. Текущая воля пользователя: сосредоточиться только на частях, для которых не найдено исправления; исключить уже исправленное и имеющее исправление в коде.

1. На «исправляй Bug N» сначала проверь наличие номера в README.md. Затем прочитай bug-NNN.md и только нужные владельцы/контракты.
2. Номера постоянны. Архив archive/2026-09-27 — исторический аудит, не очередь. Отсутствующий в активном индексе Bug не выполнять и не возвращать автоматически.
3. В составном SNN выполняй только активный объём в файле Bug. Уже исправленные части исходной цитаты, их перепроверка и дополнительные регрессионные задачи исключены.
4. «Конкретное исправление не найдено» не означает доказанного отсутствия реализации. Сначала воспроизведи выбранный баг. Найдя конкретное существующее исправление, исключи соответствующую часть из очереди и сообщи об этом; не создавай вместо неё задачу на повторную приёмку.
5. Сохраняй чужие незакоммиченные правки, IDs, варианты, EN/RU и шрифты. Серверная работа принадлежит RustyFusion; перед ней прочитай его AGENTS.md. Данные клиента — assets/game.
6. Проверяй только затронутый сценарий. Для внесённого исправления UI/анимации/звука нужна приёмка в реальном клиенте. Не запускай глобальные suites, соседние Bug или подагентов только из-за наличия этого каталога.
7. После работы обнови свой файл, активный индекс и source-list.md. Исправленную часть убери из активной очереди; исторические результаты аудита не переписывай. При необходимости новой проверки дополни verification.md точной командой и результатом.
8. Итог: что воспроизводилось, что исправлено либо уже имело исправление, какая проверка выполнена и что осталось. Сохраняй номера остальных задач.

# Bug 74 — Мобы нападают на NPC

**Приоритет:** P1. **Статус:** code-fixed 2026-10-03; живая приёмка исходного эпизода не выполнена.

## Свидетельства

T140: «Мобы нападают на НПС». В исходной таблице нет NPC/mob ID, координат или шага воспроизведения: [реестр](../../source-list-2026-10-02.md); [исходная таблица](../../evidence/2026-10-02/open-bugs-table.tsv).

## Задание

Записать mob/NPC IDs и условия агрессии, сверить правила выбора цели и защиту нейтральных NPC.

## Область и проверка

AI сервера; [server-gameplay](../../../server-gameplay.md). Мобы выбирают допустимые цели; NPC без боевого поведения не провоцируют случайный бой.

## Результат

Синтетическое воспроизведение: моб type 59, ID 2000000940; мирный NPC type 3000, ID 2000000941, в 100 единицах от моба, с маршрутом; игрок ID 1 сначала вне радиуса обзора. До исправления `NPC::can_fight()` признавал мирного NPC участником боя только из-за `path`. `ai::make_for_npc()` назначал ему `friendly_combatant`, а серверный поиск врагов допускал его как цель моба. NPC type 3000 имеет команду Friendly и AI type 0. У исходной жалобы нет реальных ID или координат, поэтому её точное место не воспроизведено.

В `../RustyFusion/src/entity/npc.rs` мирные NPC с AI type 0 и транспорт/животные с AI type 11 исключены из боя независимо от маршрута. Маршрут остаётся активным. Боевые союзники с ненулевым AI type и патрульные мобы с AI type 0 остаются участниками боя. Сравнение с `../OpenFusion/src/MobAI.cpp`: обычный автоматический поиск цели там перебирает игроков; здешние боевые союзники сохранены как принятая функциональность.

Проверки: `cargo test routed_civilian_is_not_a_mob_target --lib` — 1 passed; `cargo test ai::tests --lib` — 13 passed, 1 failed. Отдельный повтор `pack_followers_walk_with_their_roaming_leader` снова упал на проверке дистанции следования стаи; тест использует двух мобов type 59 и не затрагивает мирных NPC. Регрессия подтверждает отсутствие агрессии на мирного NPC, сохранение агрессии на подошедшего игрока, а дополнительный тест — боевой статус союзника type 1013 и патрульного моба type 2568.

Исходные локация/ID отсутствуют, поэтому приёмка именно исходного эпизода в реальном клиенте не выполнена. T140 снят как code-fixed по установленному правилу выбора цели; визуальная и сетевая приёмка остаются неподтверждёнными.

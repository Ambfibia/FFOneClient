# Bug 69 — Слой вкладки «Письма Наставника»

**Приоритет:** P2. **Статус:** исправлено 2026-10-03; клиентская приёмка RU/EN пройдена.

## Свидетельства

T108. Точный текст и координаты: [реестр](../../source-list-2026-10-02.md); [исходная таблица](../../evidence/2026-10-02/open-bugs-table.tsv).

## Задание

Проверить новую вкладку отдельно от ранее исправленной «Письма Игроков» во всех hover/selected состояниях.

## Область и проверка

Экран email; docs/native-ui.md. Вкладка занимает правильный слой относительно рамки и соседней вкладки в RU/EN.

## Результат

T108, окно email: при выборе папки «Письма Игроков» картинка вкладки «Письма Наставника» оставалась поверх верхней рамки списка. Причина — постоянный порядок соседних UI-элементов: GuideTab создавалась после картинки списка независимо от выбранной папки. Для GuideTab добавлен локальный `ZIndex`: неактивная вкладка рисуется под рамкой, выбранная или наведённая — над ней. Подписи остаются поверх арта; слой PlayerTab не менялся.

Проверки: `cargo check -p ffone-client --bin ffone-client`, `cargo build -p ffone-client --bin ffone-client --locked`, `rustfmt --check` изменённых Rust-файлов и `git diff --check` прошли. Полный клиент с `FFONE_PERF_EMAIL=1` и `FFONE_PERF_EMAIL_TABS=1` завершился без ошибок в RU и EN; проверены шесть состояний папки/наведения для каждого языка и соответствующие кадры `target/performance/bug-069-{ru,en}/tabs-0..5.png`. Сценарий использует офлайн-подачу UI; живой сервер для этой правки слоя не требуется и не проверялся.

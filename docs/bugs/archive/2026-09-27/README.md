## Как запускать

Достаточно написать: **«Исправляй Bug 1»**. Агент читает этот индекс, [правила выполнения](execution-rules.md) и файл `bug-001.md`; выполняет только выбранное задание. Примеры: «Исправляй Bug 4», «Доделай Bug 32», «Проверь Bug 1 в клиенте».

Номера постоянные: **Bug N — группа работ**, **SNN — конкретный исходный пункт**. При добавлении задач не перенумеровывать существующие. Приоритет — серьёзность исходной проблемы, а не доказательство её наличия сейчас.

## Границы проверки

Проверялась **текущая рабочая копия**, включая существующие незакоммиченные изменения. Базовые HEAD: FFOneClient `3710295a5`, RustyFusion `faba1bc`. Эти SHA не описывают весь проверенный код: рабочие деревья обоих репозиториев были изменены до аудита. Игровой код, ассеты и настройки в ходе аудита не менялись.

Пройдено **84 адресных серверных теста и 33 клиентских**, всего **117**; команды и границы покрытия — в [verification.md](verification.md). Глобальная suite не запускалась. Живой клиент, реальный геймпад, прослушивание аудио и свежие FPS/GPU-замеры в этом аудите не проверялись. Исторические GPU-отчёты не выдаются за результаты этого запуска. Не проверялось, совпадает ли уже запущенный сервер/клиент с исходниками.

Старый `docs/parity-backlog.md` и `RustyFusion/docs/openfusion-migration-audit.md` не являются актуальным статусом этих 77 жалоб. Например, замечание migration-audit о `max(current_level, nano_id)` опровергается текущим `gm_pc_give_nano` и прошедшими тестами.

## Координация

Задания сформированы для агентов, но агенты и новые задачи приложения автоматически не запускались. При одновременной работе выбирать разные владельцы; пересечения:

- Bug 4/5/20 — координаты и идентичность NPC; Bug 5/18/28 — vendor.
- Bug 1/8 — экипировка; Bug 6/9/29 — Nano и миссии.
- Bug 8/11/14 — клавиши и action state; Bug 2/27 — возврат к выбору.
- Bug 13/28 — финальные реплики; Bug 15/32 — модели Nano.
- Bug 16/36/38 — UI/локализация; Bug 12/31/33 — измерения и rendering.

Агент обновляет статус конкретных SNN и своей группы после работы, указывает выполненную проверку и оставшиеся ограничения. «Не воспроизвёл» без подходящего сценария не равно «исправлено».

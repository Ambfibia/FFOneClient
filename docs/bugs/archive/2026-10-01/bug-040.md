## Задание агенту

Проследить spawn/update/despawn удалённого игрока: запуск анимаций, заполнение HP/level/nameplate и переход видимости. Не скрывать отсутствие сетевых данных выдуманными значениями.

## Критерий готовности и проверка

На двух клиентах видны движение/действия друг друга и HP с уровнем; вход/выход из области интереса даёт плавный наплыв без зависших сущностей.

Проверить только затронутый сценарий и подходящие уникальные регрессии. Для новых UI/графики/анимаций/аудио нужен реальный клиент; для обмена/удалённого аватара — два клиента и сервер. Нулевой набор тестов не подтверждает результат. Если необходимый запуск недоступен, явно оставить живую приёмку неподтверждённой.

## Результат выполнения

Дата: 2026-10-01. Пользовательский сценарий на двух клиентах не воспроизведён: процессы ffone-client/RustyFusion отсутствуют, login/shard 23000/23001 не слушаются, FFONE_LOGIN_ADDRESS/FFONE_USERNAME/FFONE_PASSWORD не заданы. Тестовый PC ID — 17.

Установленные причины и изменения:

- T074: интерполяция каждый кадр помечала RemoteAnimation изменённым, presenter выдавал новую revision и перематывал клип. Теперь Changed публикуется только при смене состояния; одинаковое движение не перезапускается от MOVE/HP. Запрос упорядочен после интерполяции и до общего animation apply. Resolver повторяет ожидание каталогов, вместо потери первого PendingPcVisual при ещё не готовых ресурсах.
- T074, действия: broadcast PC_ATTACK_NPCS/PC_ATTACK_CHARS терял ID атакующего при проекции в results. Теперь ID сохранён и после строгого decode запускается профильная атака удалённого PC. Конец атаки/эмоута определяется по текущему клипу и revision, затем восстанавливается idle/движение.
- T076: надпись выбранного PC намеренно создавалась без HP. Добавлены HP fill и уровень под именем. HP/level/class приходят из PcAppearance; maximum HP следует принятому контракту роста (1000 на уровне 1, +75 за уровень, бонус класса). При уровне вне 1..40 strip скрыт, current HP не подменяет maximum HP. EN/RU и replacement font сохранены.
- T079: мгновенные reveal/despawn заменены переходом 0,5 секунды после readiness. Fill, outline и attachments получают приватные материалы; alpha/pass восстанавливаются после появления. EXIT сразу освобождает ID и удаляет network/target/motion компоненты; root удаляется после затухания. Возврат того же ID создаёт новый root. Disconnect очищает также retiring roots.

Изменены `world_systems/remote`, `world_systems/entity_lifecycle`, `world_systems/network_world_runtime` (новый `pc_visibility.rs`), `ui/gameplay/combat_target` и адресные регрессии. Wire-формат, IDs, assets/game и RustyFusion не менялись.

Добавлены проверки: Changed только при lag stop; повторные MOVE/HP без перемотки; attack broadcast и malformed tail; HP/level/class; приватные fill/outline и восстановление pass; освобождение ID, возвращение и session cleanup. Результаты выполненных проверок:

Повтор одного codec-теста исключён из суммарных 56 уникальных passed.

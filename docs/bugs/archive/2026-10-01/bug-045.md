## Задание агенту

На машине времени проследить условия показа выбора гида и переход к guide UI. Согласовать состояние гида и серверный запрос, сохранив существующий выбор.

## Критерий готовности и проверка

В нужном сценарии машина времени предлагает выбор гида, подтверждение применяется сервером и не теряется при переходе.

Проверить только затронутый сценарий и подходящие уникальные регрессии. Для новых UI/графики/анимаций/аудио нужен реальный клиент; для обмена/удалённого аватара — два клиента и сервер. Нулевой набор тестов не подтверждает результат. Если необходимый запуск недоступен, явно оставить живую приёмку неподтверждённой.

## Результат выполнения

Причина: `Connecting` и `LoginMetadata` могли быть обработаны одним `poll_network`; отложенный `reset_guide_vendor_on_network_boundary` после poll обнулял новый `payment_flag`. `guide_service_entry(23, None)` исключал WARP TO PAST у Time Machine, NPC type 1175. Теперь ingress очищает старую метаинформацию в порядке событий на Connecting/Error/Disconnected; отложенный сброс закрывает UI, сохраняя уже полученную новую метаинформацию. Возврат к roster закрывает только shard и сохраняет флаг действующей login-сессии: worker не присылает LoginMetadata повторно. Существующие ID гида, выбранный гид, подтверждение, серверные запросы и маршрут warp 76/NPC 1425 сохранены.

Проверки 2026-10-01: gameplay guide — 12 passed; guide UI — 18 passed; session lifecycle — 2 passed; две проверки корреляции mentor reply — 2 passed. Клиентская проверка RU/EN завершена: предупреждение, выбор Dexter, подтверждение/отмена и сообщение 111 — PASS, оба запуска exit 0; серверный переход/повторный вход не подтверждены (login/shard 23000/23001 не слушаются, FFONE_LOGIN_ADDRESS/FFONE_USERNAME/FFONE_PASSWORD не заданы).

Сборка `cargo build -p ffone-client --bin ffone-client --locked` успешна; использован `target/debug/ffone-client.exe` от 2026-10-01 11:09:51. RU/EN кадры выбора и подтверждения осмотрены: описания наставников локализованы и помещаются в карточки. Полная UI-проверка использует opt-in offline fixture `FFONE_PERF_SERVICE_DIALOGUE`; серверное подтверждение, warp 76 и повторный вход этим запуском не проверяются. Подробные команды, результаты и ограничения — в [журнале проверок](../../verification.md).

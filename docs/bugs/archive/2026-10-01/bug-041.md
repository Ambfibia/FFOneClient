## Задание агенту

Установить escort mission/NPC и проверить серверное состояние сопровождения, начало маршрута, следование и завершение. Членство NPC в группе само по себе не считается запуском сопровождения.

## Критерий готовности и проверка

NPC следует за игроком в нужной миссии, корректно реагирует на отставание и завершает этап без зависания прогресса.

Проверить только затронутый сценарий и подходящие уникальные регрессии. Для новых UI/графики/анимаций/аудио нужен реальный клиент; для обмена/удалённого аватара — два клиента и сервер. Нулевой набор тестов не подтверждает результат. Если необходимый запуск недоступен, явно оставить живую приёмку неподтверждённой.

## Результат выполнения

2026-10-01. T036 снят из активной очереди как code-fixed.

Причина подтверждена кодом и таблицами RustyFusion: NPC с m_iAiType=0 получает loose_follow и Always tick при запуске миссии, но движение выполняется только отсутствующим Lua AI. NPC 2567 (цепочка 5209 → 5211, mission 840, map 143) также имеет обе скорости 0. Членство в группе само по себе движение не запускает. Клиент дополнительно терял escort entity ID на этапе 5211 типа 2; сервер принимал временный путь следования за незавершённый авторский маршрут.

Исправление в ../RustyFusion: новый src/escort.rs управляет mission-owned следованием независимо от idle AI и социальных групп. Delivery определяется по terminator NPC для типа 6 либо m_iCSUDEPNPCFollow; defence сохраняет авторские маршруты. Ограниченная очередь точек, скорость 800 centiunits/s и дистанция остановки 200 взяты из локального OpenFusion Escorts/ EscortTrail. Отставание блокирует END до прибытия; сервер проверяет владельца, задачу, жизнь, instance и близость игрока/NPC/цели (500 centiunits). При отмене, смене instance, потере игрока или скачке позиции >5000 escort освобождается; исходный маршрут и AI восстанавливаются. Потерянный escort даёт обычную серверную ошибку EscortFailed через player tick.

Изменены владельцы сервера: src/escort.rs, src/entity/npc.rs, src/entity/player.rs, src/mission.rs, src/tabledata.rs, src/lib.rs, src/server/shard/mission.rs, регистрация и отдельные escort_tests.rs в shard. В FFOneClient изменены mission_runtime/operations.rs и адресная регрессия в tests/input.rs: entity ID разрешается для любого этапа с escort NPC, включая 5211.

Проверки:

- cargo test --lib escort -- --test-threads=1 в RustyFusion: **4 passed**. Реальные handlers GROUP_INVITE → TASK_START → NPC_MOVE → TASK_END → TASK_START → TASK_END для 5209/5211; отставание запрещает преждевременное завершение, после прибытия этап завершается. Fixture в памяти без пользовательской БД.
- Отдельные регрессии: отмена, смена instance, телепорт и восстановление исходного pending route; delivery/defence classification для 576, 5209, 5211, 5229, 5236, 5237 и 1753, 1038, 872.
- cargo test --lib ai::tests:: -- --test-threads=1: **12 passed**, включая авторские маршруты, roaming, retreat и pack followers.
- cargo check --lib --locked и cargo build --bin hybrid --locked RustyFusion: успешно; адресный git diff --check: успешно.

Ограничения: это серверные packet-handler round trips, а не TCP/shard проход в полном клиенте. cargo test -p ffone-client --lib escort_requests_resolve_live_owners --locked был остановлен после длительного ожидания общей очереди сборки; тест не начал выполняться. Живая приёмка движения, реакции на отставание и завершения конкретной миссии в FFOneClient не выполнена. Исходный пользовательский NPC/mission ID в T036 не указан; не утверждается, что жалоба была воспроизведена визуально именно на его персонаже.

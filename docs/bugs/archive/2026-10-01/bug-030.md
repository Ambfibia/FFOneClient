**Приоритет:** P2. **Статус:** code-fixed 2026-10-01; аудиопереходы проверены в полном клиенте на синтетических offline-состояниях. Серверные порталы и пользовательская оценка выбранной композиции не подтверждены.

## Задание агенту

Определить правильный Downtown track/route и приоритеты музыки локации, заражённой зоны и перехода. При выходе переключать музыку по состоянию мира, не ждать естественного окончания старой записи.

## Критерий готовности и проверка

В Downtown играет согласованная музыка; вход/выход из нескольких заражённых зон и машины времени переключает её вовремя, без наложений.

Проверить только затронутый сценарий и подходящие уникальные регрессии. Для новых UI/графики/анимаций/аудио нужен реальный клиент; для обмена/удалённого аватара — два клиента и сервер. Нулевой набор тестов не подтверждает результат. Если необходимый запуск недоступен, явно оставить живую приёмку неподтверждённой.

## Результат выполнения

2026-10-01, T002: по просьбе пользователя возвращён обычный `05 Midtown` из последнего локального Retrobution 20260821. Три Downtown-полигона 60–62 использовали альтернативный `Midtown V1`; теперь они используют `music/05_midtown`, как соседний полигон 63. Остальные специализированные треки Downtown и IDs/границы/порядок полигонов сохранены. `05 Midtown` (PastMusic.resourceFile, AudioClip 8) уже присутствовал в native assets и побайтно совпал с последним raw-билдом: SHA-256 `6fe7a7e168933b6bbcac4984bd79cdaf9bf6f4389cbc60c2dbf972c9ff7e6269`. Повторная запись одинакового OGG не потребовалась. Проверка источника выполнена адресно через FusionForge `inspect` и `dump-object-evidence`, без промежуточной распаковки.

T045: выбор музыки ранее оставлял текущий канал нетронутым, если cooldown первого подходящего полигона ещё не закончился либо нового полигона вообще не было. Теперь канал запоминает выбранный полигон: вход/выход выбирает новый трек независимо от replay delay, отсутствие подходящей зоны останавливает прежний трек; задержка повтора внутри той же зоны сохранена. После loading/одноразового server override производится свежий выбор. Существующие fade-out 0.5 s, fade-in 1 s и scan 1 s сохранены; переход не ждёт естественного конца записи. Соседние полигоны с одним logical key продолжают текущий источник.

Изменены `assets/game/data/audio/retrobution-world.json`, `crates/ffone-client/src/world_systems/audio/{mod.rs,tests.rs}`. Новая регрессия проверяет возврат из infected music в каждый Midtown-полигон при активном cooldown, сохранение cooldown внутри того же полигона и остановку вне всех зон.

Проверки: **7 аудио-тестов passed**, включая новую регрессию и прежние уникальные проверки warp/loading/lair, порядка полигонов и непрерывного источника на соседних участках. Сборка `cargo build -p ffone-client --bin ffone-client --features diagnostics --locked` успешна; финальный проверенный бинарник — 2026-10-01 12:33:52.

В полном клиенте выполнен opt-in `FFONE_PERF_AUDIO=1`: Midtown (61) → Pokey Oaks Junior High (4) → Midtown → Mandark's House (5) → Midtown → Time_machine (102) → Midtown. **7/7 этапов passed**, реальные `AudioSink` содержат ожидаемые записи, одновременно активна максимум одна world music запись, exit 0. Возврат Midtown выполнялся внутри его 45 s cooldown. Для Time_machine использован центр первой комнаты, поскольку центр всего составного полигона находится вне зоны. Сценарий хранится в `crates/ffone-client/src/app/performance_probe/audio_regression.rs`; его запуск подключён к существующему offline probe. Он отбрасывает ошибки фоновой сети без shard, которые иначе выдают `stop`, и управляет координатами/instance-состоянием для аудиопроверки. Обычный runtime не меняет обработку сетевых ошибок.

Ограничения: это полный клиент с настоящими аудиоканалами, но синтетические offline-переходы, без серверного прохода порталов. Оба Downtown-варианта (`05 Midtown`, `Midtown V1`) совпадают с последним raw-билдом; выбран обычный `05 Midtown`, выбор композиции был отдельно предложен пользователю для уточнения. T002 и T045 сняты как code-fixed, без заявления о пользовательской/серверной приёмке. [Точные проверки](../../verification.md).

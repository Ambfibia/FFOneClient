# Bug 44 — Анимации NPC: мирная ходьба и преждевременный повтор

**Приоритет:** P2. **Статус:** code-fixed; код исправлен 2026-10-01, визуальная проверка завершена 2026-10-02. 12 серверных и 10 клиентских тестов прошли; полный клиент проверен с offline packet replay. Живой shard не проверялся.

## Объём и свидетельства

- [T063](../../source-list.md#t063) — Мобы вместо анимации свободной ходьбы вне боя используюют бег боя.
- [T064](../../source-list.md#t064) — НПС с анимацией слишком быстро начинают анимацию заново.

Исправленные корабельные жесты Декстера не возвращаются в работу. Нужен конкретный иной NPC/клип.

## Задание агенту

Различить состояние спокойной ходьбы и боевого бега. Установить NPC/клип, который перезапускается раньше конца; проверить повторную установку анимации системой и авторскую длительность.

## Критерий готовности и проверка

Вне боя моб использует мирную ходьбу, в бою нужный бег; жест NPC не перезапускается до завершения и возвращается в правильное состояние.

Проверить только затронутый сценарий и подходящие уникальные регрессии. Для новых UI/графики/анимаций/аудио нужен реальный клиент; для обмена/удалённого аватара — два клиента и сервер. Нулевой набор тестов не подтверждает результат. Если необходимый запуск недоступен, явно оставить живую приёмку неподтверждённой.

## Результат выполнения

### 2026-10-01

- **T063:** мирный NPC type 59 (Tech Queen), ID `2000000901`, наблюдатель вне sight range. `idle_roam` вызывал `move_to` без скорости; native `NPC::move_towards` выбирал run speed для расстояния выше `NPC_RUN_DISTANCE=200`. Теперь Luau явно задаёт walk speed. Мирный участник pack также ограничен walk speed; боевой лидер/отступление сохраняют прежнюю скорость.
- **T064:** Bad Max, type 461, `characters/mobs/mob_ammonia/mob_ammonia.glb`, idle `stand1`–`stand4`. У `stand2` событие `end` стоит на 2.75 s, последние ключи — 2.9999986 s. Runtime выбирал следующий idle на раннем событии и обрезал хвост жеста. Обычные NPC и HNPC теперь выбирают следующий idle после полного цикла (`completions`); боевые события `end` сохранены. Пример HNPC-регрессии — `rifleguard`, end 5.0833335 s, цикл 5.3333335 s.
- Изменены серверные `scripts/lib/behaviors.luau`, `scripts/ai/mob_pack_member.luau`, адресные проверки в `src/ai_tests.rs`; клиентские владельцы `animation_play_network_npc_animation.rs`, `animation_sync_network_hnpc_animation.rs`, `animation_tests.rs`, `tests/animation.rs`. Добавлен opt-in `FFONE_PERF_NPC_IDLE` в существующий full-client replay.
- **Сервер:** финальный `cargo test --lib ai::tests:: --locked -- --test-threads=1` — **12 passed**, 0 failed. Проверены исходящие Walk-пакеты одиночного моба/pack, сохранены проверки боя, отступления и authored routes. Первоначальное падение patrol-теста при финальном повторе не воспроизвелось.
- **Клиент:** `cargo test -p ffone-client --lib hnpc_idle_preserves --locked` — **1 passed**; `target/debug/deps/ffone_client-300cdf94d89a9153.exe npc_bad_max --test-threads=1` (только что собранный этим Cargo test бинарник) — **9 passed**, 0 failed. Новые регрессии проверяют полные idle-циклы настоящего GLB Bad Max и отсутствие перемотки walk/run при повторных motion-пакетах. HNPC проверяет полный цикл rifleguard, смену idle после завершения, переходы в walk/death. Существующие проверки боевых слоёв/end также прошли. Первая компиляция остановилась на текущих изменениях UI обмена, финальная — успешна.
- **Полный клиент, финальная приёмка 2026-10-02:** успешная `cargo build -p ffone-client --bin ffone-client --features diagnostics --locked`; отдельная копия бинарника в `target/bug044-runtime`, exit code **0**. `FFONE_PERF_NPC_IDLE=1`, `FFONE_PERF_POSITION='-6434.3188 -56.4746 668.2039'`, NPC ID `1904461`, type 461, Южный Пич-Оукс. Три idle-снимка и отдельные walk/run-снимки в `target/bug044-clear` визуально осмотрены; принятый размер и GLB не менялись. Камера fixture охватывает модель целиком.
- Replay содержит **112 наблюдений**. `stand2 → stand1` (доминирующая поза на кадре 190) и `stand1 → stand2` (кадр 310) происходят при `completions=1` предыдущего клипа. На кадре 400 активен `walk`, weight 1, seek 0.6355 s; на 520 — `run`, weight 1, seek 0.6833 s. Преждевременный выбор idle отсутствует; пакеты Walk/Run дают разные native клипы.
- Первые два GPU-запуска (`target/bug044-idle`, `target/bug044-framed`) дали корректные времена, но отвергнуты для визуальной приёмки: слишком близкая камера, затем перекрытие листвой. Финальный запуск `target/bug044-clear` выполнен с полным кадрированием. Показатели FPS этих captures не оценивались.
- **T063 и T064 сняты из активной очереди как code-fixed.** Полная игровая приёмка на живом shard и отдельный GPU-сценарий HNPC не подтверждены; HNPC покрыт адресной проверкой реального AnimationPlayer/полного цикла. Исторические корабельные жесты Декстера не перепроверялись.

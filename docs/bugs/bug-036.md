## Задание агенту

Составить точный список неудачных портретов из воспроизводимого UI и вернуть соответствующие старые native-иконки по сохранённым IDs. Не заменять весь набор без причины.

## Критерий готовности и проверка

Затронутые NPC показывают согласованные старые иконки с правильной рамкой, масштабом и маршрутом.

Проверить только затронутый сценарий и подходящие уникальные регрессии. Для новых UI/графики/анимаций/аудио нужен реальный клиент; для обмена/удалённого аватара — два клиента и сервер. Нулевой набор тестов не подтверждает результат. Если необходимый запуск недоступен, явно оставить живую приёмку неподтверждённой.

## Результат выполнения

Заполнить: дата; конкретное воспроизведение/ID/сборка; установленная причина; изменённые файлы; точные проверки и результаты; ограничения; статус каждого TNNN. После исправления убрать задачу из активного индекса и перенести карточку с результатом в датированный архив, сохранив Bug ID.

# Bug 57 — Экран входа после отключения сервера

**Приоритет:** P0. **Статус на 2026-10-05:** активно; объём ниже не закрыт.

## Свидетельства

[T096](source-list.md#t096), [T202](source-list.md#t202).

## Оставшийся объём

Экран логина зависает при остановке сервера. Сброс busy при уже полученном Network error/Disconnected в коде есть, но не подтверждает получение события при остановке сервера во время ожидания. Воспроизвести оба состояния.

## Критерий готовности

Показывается ошибка, ввод доступен и повторный вход после запуска сервера работает.

Выполнить адресные регрессии и приёмку изменённого поведения в реальном клиенте. Для обмена/удалённого игрока — два клиента и сервер; для hot-plug — физическое устройство. Нулевой набор тестов не считается проверкой. Ограничения записать явно.

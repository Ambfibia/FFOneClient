# Bug 44 — Блуждание фьюженов

**Приоритет:** P2. **Статус на 2026-10-05:** активно; объём ниже не закрыт.

## Свидетельства

[T135](source-list.md#t135), [T230](source-list.md#t230).

## Оставшийся объём

Фьюжены не гуляют вне боя. Это отдельный остаток после исправления скорости Walk и полных idle-циклов. Найти конкретный NPC, его AI и допустимый маршрут.

## Точки входа

Найти владельца через [source-map](../source-map.md), затем искать точные символы и читать только совпавшие диапазоны.

Контракты: gameplay/network; точные документы и правила — в [AGENTS.md](AGENTS.md). Перед изменением RustyFusion прочитать его AGENTS.md.

## Критерий готовности

Указанный фьюжен использует предусмотренное мирное блуждание, боевые скорости/сброс не повреждены.

Выполнить адресные регрессии и приёмку изменённого поведения в реальном клиенте. Для обмена/удалённого игрока — два клиента и сервер; для hot-plug — физическое устройство. Нулевой набор тестов не считается проверкой. Ограничения записать явно.

## Результат следующего выполнения

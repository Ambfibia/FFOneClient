# Bug 73 — Неподвижные акторы используют движение

**Приоритет:** P1. **Статус:** частично code-fixed 2026-10-03; T145 и живая приёмка остаются.

## Свидетельства

T138, T139, T141-T147. Точный текст и координаты: [реестр](source-list-2026-10-02.md); [исходная таблица](evidence/2026-10-02/open-bugs-table.tsv).

## Задание

Проверить перечисленные NPC и объекты по ID/локациям; разделить неверные флаги данных, AI и клиентскую анимацию. Не превращать все объекты в неподвижные по одному примеру.

## Область и проверка

NPC/объекты мира; docs/server-gameplay.md и docs/native-asset-workflow.md. Найти владельца через [source-map](../source-map.md), читать только совпавшие диапазоны. Перед правкой RustyFusion прочитать его AGENTS.md. Каждый перечисленный актор использует свой предназначенный режим, а действующие NPC сохраняют маршруты. Выполнить адресные проверки и приёмку изменённого поведения в реальном клиенте; ограничения записать без заявления о полной приёмке.

## Результат

### Причина и исправление (2026-10-03)

`NPCs.json` хранит ключи размещения с нуля, а `paths.json` содержит `aNPCIDs` в серверном пространстве OpenFusion: ID = ключ + 1 (`NPC_ID_OFFSET = 1`). RustyFusion ошибочно сравнивал значения напрямую. Маршрут машины попадал следующему NPC, а клиент правильно получал `P_FE2CL_NPC_MOVE` и показывал движение/анимацию. Исправлен перевод `aNPCIDs` в ключ размещения при загрузке маршрутов в `../RustyFusion/src/tabledata.rs`; данные и сетевые ID не переписаны.

Для T145 «номер 133» текущий runtime ID 133 указывает на Reactor Works, тип 1229, ключ 1116. Ни по ключу, ни по серверному ID 1117, ни по типу маршрута нет. Если имелся в виду тип 133, это другой NPC. Пункт остаётся активным до воспроизведения и уточнения ID/типа.

Проверено: `cargo test placement_paths_follow_source_ids_across_channels_and_honor_loop_flag --lib --quiet` — 1 passed; `cargo test every_placed_bundled_npc_route_advances_without_a_watcher` — 1 passed; `git diff --check -- src/tabledata.rs` — успешно. Первый тест проверяет все восемь соседних размещений, второй — движение акторов с маршрутом. Живая проверка указанных локаций в клиенте не выполнена: при работе процессы клиента/сервера не были запущены, переменные FFONE_USERNAME/FFONE_PASSWORD не заданы. Поэтому T138/T139/T141–T144/T146/T147 — code-fixed, но визуальная приёмка остаётся; Bug 73 остаётся активным для T145 и этой проверки.

# Bug 54 — Дальность пузырьков NPC

**Приоритет:** P2. **Статус на 2026-10-05:** активно; объём ниже не закрыт.

## Свидетельства

[T088](source-list.md#t088), [T183](source-list.md#t183).

## Оставшийся объём

После исправления стен пузырьки видны слишком близко. Пересмотреть дистанцию по сценарию пользователя, сохранить occlusion через геометрию и скрытый первый кадр.

## Точки входа

Найти владельца через [source-map](../source-map.md), затем искать точные символы и читать только совпавшие диапазоны.

Контракты: UI, rendering; точные документы и правила — в [AGENTS.md](AGENTS.md). Перед изменением RustyFusion прочитать его AGENTS.md.

## Критерий готовности

Дальность принята в открытом пространстве; за стеной пузырь скрыт и после выхода снова виден без вспышки.

Выполнить адресные регрессии и приёмку изменённого поведения в реальном клиенте. Для обмена/удалённого игрока — два клиента и сервер; для hot-plug — физическое устройство. Нулевой набор тестов не считается проверкой. Ограничения записать явно.

## Результат следующего выполнения

Заполнить конкретное воспроизведение, причину, исправление и выполненные проверки. Исправленный объём удалить из очереди; при полном закрытии удалить карточку и строку README, без архива. Сохранять уникальные регрессионные тесты и принятые IDs, variants, EN/RU и replacement fonts.

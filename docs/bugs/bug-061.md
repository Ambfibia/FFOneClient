## Критерий готовности

На проблемном этапе журнал открывается/закрывается и туториал продолжается с сервером.

Выполнить адресные регрессии и приёмку изменённого поведения в реальном клиенте. Для обмена/удалённого игрока — два клиента и сервер; для hot-plug — физическое устройство. Нулевой набор тестов не считается проверкой. Ограничения записать явно.
